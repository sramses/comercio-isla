# Comercio Isla

## Descripción
Comercio Isla es una plataforma de comercio electrónico para una pequeña empresa cubana.

## Objetivo
Permitir que los clientes consulten productos, agreguen artículos a un carrito y realicen pedidos en línea.

## Tecnologías previstas
- React para la interfaz web.
- Node.js y Express para el servidor.
- PostgreSQL para la base de datos.
- JWT para la autenticación.

## Estado del proyecto
En desarrollo, como parte del taller integrador de Aplicaciones Web.
